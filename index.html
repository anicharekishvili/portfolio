ჩემ შესახებ

მე ვარ დამწყები ვებ-დეველოპერი, რომელიც დაინტერესებულია თანამედროვე ვებ-ტექნოლოგიებით, მარტივი, სუფთა და მომხმარებელზე ორიენტირებული ინტერფეისების შექმნით.

ჩემი მიზანია შევქმნა ისეთი ციფრული პროდუქტები, რომლებიც არის ხელმისაწვდომი, სწრაფი და ფუნქციური.

უნარები და ტექნოლოგიები

ტექნიკური უნარები:

  • HTML5 — სემანტიკური მარკაპი, ფორმები, ცხრილები
  • CSS3 — სტილები, განლაგება, ადაპტური დიზაინი
  • JavaScript — საბაზისო ლოგიკა, DOM-თან მუშაობა
  • Git & GitHub — ვერსიების კონტროლი და კოდის მართვა
  • Figma — Wireframing, UI დიზაინი, პროტოტიპირება

პიროვნული უნარები (Soft Skills):
